Drop a cover image into each project's folder to replace the generated placeholder:

- `bonfire/cover.jpg`
- `solana-vault/cover.jpg`
- `haunted-dorm/cover.jpg`
- `placeholder/cover.jpg`

Accepted extensions: `.jpg`, `.jpeg`, `.png`, `.webp`. Once a `cover.*` file exists, the site picks it up automatically via `lib/images.ts` — no code changes needed.
